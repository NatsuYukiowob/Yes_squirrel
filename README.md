# 對對對松鼠迷因 (Yes Squirrel Meme)

這是一個極致紓壓的「對對對」松鼠迷因產生器/按鈕網頁。

專為實況主、迷因愛好者以及需要發洩壓力的人所設計，只要按下按鈕，就能享受到最純粹的「對！」體驗。

## ✨ 核心特色

*   **無縫音軌疊加 (Polyphony)**：點擊多快，聲音就疊多厚，拒絕音效切斷，享受極致的洗腦感。
*   **鬼畜連擊系統 (Combo System)**：
    *   內建連擊計數器，挑戰你的手速極限。
    *   **Max Combo 紀錄**：自動保存在本地瀏覽器，每次打開都能挑戰過去的自己。
*   **🔥 鬼畜狂熱模式 (Fever Mode)**：
    *   當 Combo 達到 30 以上，畫面會進入 RGB 霓虹閃爍狀態。
    *   **變聲系統 (Pitch Shift)**：隨著連擊數增加，松鼠的聲音會越來越尖銳、語速越來越快，最高可達 2.5 倍速！
    *   附帶獨立開關，可隨時開啟或關閉此極限體驗。
*   **多重觸發方式**：
    *   滑鼠/手機觸控點擊。
    *   支援鍵盤 **空白鍵 (Space)** 與 **Enter 鍵** 觸發（支援實體實況按鈕踏板）。
    *   內建 **x10 連發** 與 **x100 爆發** 按鈕，一鍵解放雙手。
*   **豐富的視覺彩蛋**：
    *   每次點擊噴發隨機迷因文字（「對！」、「確實！」、「沒錯！」...）。
    *   背景震動打擊感。
    *   特定 Combo 數觸發「巨大金色字體」與「全螢幕高反差閃爍」。

## 🚀 部署與使用方式

本專案為純靜態網頁 (HTML/CSS/JS)，無需安裝任何伺服器環境。

1. 將本專案下載或 Clone 到本地。
2. 直接點擊兩下 `index.html`，使用任何現代瀏覽器開啟即可遊玩。
3. 若要發布到網路上，只需將整個資料夾上傳至 GitHub 並開啟 **GitHub Pages** 即可免費託管。
